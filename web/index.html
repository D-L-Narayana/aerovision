Vision-language perception that drone agents can act on

CLIP ViT-B/32 (Hugging Face transformers.js, WASM) classifies aerial scenes zero-shot with a 4-template prompt ensemble, a linear probe trained on frozen CLIP features lifts accuracy on the 21 UC Merced land-use classes, and a deterministic radiometric hotspot detector turns thermal frames into SOP-graded anomalies. Everything is emitted as a schema-validated InspectionReport — the same contract the Python package hands to an agent tool loop.
